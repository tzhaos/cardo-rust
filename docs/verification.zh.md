# v0.3.0 验证记录

[English](verification.md) · [首页](../README.zh.md)

记录日期：2026 年 9 月 24 日，Windows x64。本轮没有新增测试或烟雾测试代码，源码与构建检查、实际运行观察分别记录。

## 构建与静态检查

- 框架全部 feature 的 `x86_64-pc-windows-msvc` release 构建。
- `cardo-runtime`、`cardo-app` 无默认 feature 检查。
- 独立桌面模板默认配置及启用 `update` 的 release 构建，保留自己的锁文件和应用版本。
- 模板与 runtime 三种语言的消息键和参数对齐。
- 框架 crate 和模板没有下游产品依赖或身份。
- 源码检查覆盖目标窗口输入工厂、弱引用任务交付、保存快照、单实例线程退出和更新路径、包内清单检查。

## 实际观察

- Cardo Desk 独立运行，对 1,067 字节本地文件进行流式 SHA-256，结果与系统哈希工具一致。
- 主页、设置、关于导航可用。初次发现窗口图标缺失及标题栏拦截导航点击，修复并构建后重新观察正常。
- 设置将简体中文与深色外观保存到模板自己的 TOML。保存通知出现后自动消失，未进行毫秒级计时。
- 运行中外部编辑 TOML 后，保存被拒绝并显示带路径的冲突信息，没有覆盖外部文件。
- 第二次启动把文件交给现有窗口并成功退出。
- 消费应用实际走过原生表单打开、再次打开、取消、Escape、Alt+F4；目标窗口输入获得焦点，后台任务完成与完成/跳过通知已观察。

## 尚未覆盖

- 强制原生开窗失败、完整焦点恢复矩阵、快速替换竞态、工作线程期间宿主销毁、原生选择器中断。
- Toast 边界拖动、替换计时竞态、全部 DPI 与多显示器组合、完整长文本及菜单边界。
- 全部快捷键冲突、禁用、录制组合，以及每种设置验证和保存失败路径。
- 本次抽取后**未执行**隔离更新下载取消、坏包拒绝、安装版/绿色版应用、更新中断恢复和回滚；源码检查与构建通过不能代表这些运行结果。
- 本地日志仍有 GPUI 原生窗口/无障碍诊断，本版不宣称完整视觉、无障碍或跨平台验收。
